# Website Kelas XI TAV Madugo

Website profil dan informasi **Kelas XI Teknik Audio Video (TAV) – SMK Ma'arif 2 Gombong**.

## ✨ Fitur

- 🏫 Profil kelas
- 👥 Struktur organisasi
- 📚 Jadwal pelajaran
- 👨‍🎓 Daftar siswa
- 🖼️ Galeri dokumentasi
- 📢 Pengumuman / agenda kelas
- 📱 Tampilan responsif
- 🔎 Dukungan `sitemap.xml` untuk mesin pencari
- 🤖 `robots.txt`

## 📁 Struktur Proyek

```text
.
├── index.html
├── sitemap.xml
├── robots.txt
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    └── gambar dan aset website
```

> Pastikan semua gambar/aset yang dipanggil oleh HTML, CSS, dan JavaScript ikut diunggah agar tidak hilang setelah deploy.

## 🚀 Menjalankan

Tidak membutuhkan framework atau proses build.

```bash
git clone https://github.com/kohko979-lang/wesite-kelas-11-tav-madugo.git
cd wesite-kelas-11-tav-madugo
```

Kemudian buka `index.html` di browser, atau gunakan **Live Server** di Visual Studio Code.

## 🌐 Deploy

Website dapat di-deploy melalui Netlify atau GitHub Pages.

Pastikan `index.html`, `sitemap.xml`, dan `robots.txt` berada di root repository.

Sitemap:

```text
https://kelas-tavmadugo.netlify.app/sitemap.xml
```
